# Синтез фазового ДОЭ

Четыре изображения 128×128 подаются в порядке расстояний 24,1 / 25,3 / 26,5 / 27,7 мм. Каждый вход должен быть 8-битным PNG в оттенках серого.

Модель обрабатывает цели совместно. В её слоях используется распространение Френеля с одним FFT для длины волны 532 нм и шага маски 10 мкм. Веса находятся в `weights/submission_v2.pt` и загружаются из образа.

## Запуск в Docker

В корне репозитория создайте папку `images` и положите туда четыре входных файла: `1.png`, `2.png`, `3.png` и `4.png`.

```sh
docker build -t four-plane-doe .
docker run --rm --network none --mount "type=bind,source=${PWD}/images,target=/images" four-plane-doe /images/1.png /images/2.png /images/3.png /images/4.png --output /images/doe.png
```

Маска сохранится в `images/doe.png`. Это 8-битный PNG 128×128 в оттенках серого. Код 0 соответствует фазе −π, код 255 соответствует +π.
